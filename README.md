### Satellite-constellation-simulator
Данная модель позволяет увидеть качественные характеристики связи АТ с LEO спутниками (Миссия Р4 в 2027году) во время выполнения тестового сценария - определение своего местоположения со стороны АТ через GEO спутники и последующего установления связи с LEO группровкой
Важное замечание: количество спутников для данного программного фикса для АТ и КА учитывается для группировки Р4 - 250 шт. В случае другого количества, необходимо произвести повторное моделирование, где результаты, в случае меньшего числа спутников, будут значительно хуже
